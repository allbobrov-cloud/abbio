# SEO-аудит ABBiO — 29 сентября 2026

> Обновление после аудита, 29.09.2026: владелец подтвердил текущие факты сайта, в том числе имена, роли и портреты команды, а также показатели кейсов. Замечания ниже о неподтверждённой команде и числах описывают состояние и доступные аудитору данные на момент первоначальной проверки; они не являются текущим запросом на повторное подтверждение. Устаревшие видимые пометки о демо-команде удалены в последующей локальной правке.

## Область и ограничения

Проверены текущая локальная версия `http://localhost:3000` (16 маршрутов, серверный HTML, исходники Next.js и технические URL) и подтверждённый владельцем публичный домен `https://abbio.ru` (10 основных маршрутов, технические URL, HTTP/HTTPS и зеркало `www`). Это аудит готовности к поисковому продвижению, а не оценка позиций. Доступа к Google Search Console, Яндекс Вебмастеру, данным реального трафика и полевым Core Web Vitals не было; фактическое состояние индекса не подтверждено. Числовой SEO-рейтинг не выставлялся: без этих данных он был бы ложной точностью. Исходники сайта не менялись в рамках аудита.

## Краткий итог

Опубликованный сайт **сейчас закрыт от индексации**. Общий `src/app/layout.tsx` задаёт `noindex, nofollow`: это подтвердилось в HTML всех 16 локальных страниц и на 10 проверенных публичных страницах. При этом каркас уже пригоден для дальнейшей работы: локальные страницы возвращают 200, отдают основной контент в HTML, имеют по одному H1, уникальные title и description, `lang="ru"`; все проверенные страницы достижимы по обычным внутренним ссылкам с главной.

### Замечания по отдельным страницам

- **Главная:** демо-команда честно маркирована, но для публичного сайта нужны реальные сведения о людях или иной доказательный блок. Нельзя заменять их вымышленными ролями.
- **Кейсы:** у части страниц мета-заголовок состоит почти только из названия клиента (`/cases/oss`, `/cases/volhonka`, `/cases/bogov`). Его можно уточнить выполненной работой после сверки фактов. Для чисел и результатов нужен первичный источник с датой/периодом. В кейсе Bogov есть дата и выборка для 94%, но комментарий в исходнике сообщает, что подтверждающих данных проекта пока нет (`BogovHero.tsx:7`).
- **Статьи:** не создавать массовые шаблонные тексты. Первые публикации должны отвечать на реальные вопросы клиентов и опираться на опыт ABBiO, примеры работ и авторство.
- **Контакты и документы:** в футере нет утверждённых контактов. В исходниках не обнаружена страница политики/согласия для формы. Эти сведения должен предоставить владелец; юридическое содержание нельзя придумывать.

## Что уже работает

- 16 проверенных маршрутов возвращают HTTP 200. Неизвестные маршруты обрабатываются страницей 404.
- Контент, заголовки и ссылки присутствуют в серверном HTML; JavaScript не требуется для обнаружения основных страниц.
- На всех 16 маршрутах один H1, уникальные title и description, русский язык документа.
- Все 16 проверенных страниц достижимы из главной по HTML-ссылкам. Разделы услуг и кейсов связаны общей навигацией.
- Большинство иллюстраций отдаются через `next/image` с современными форматами и адаптивными размерами. Это хорошая база, но показатели LCP/INP/CLS надо измерить отдельно на опубликованном домене.

## Проверки перед публикацией

1. Использовать подтверждённый основной URL `https://abbio.ru`; исправить сертификат и редирект `www`, определить целевые регионы, проверить варианты слеша.
2. Подтвердить реальные контакты, команду, результаты кейсов, тексты обработки данных и рабочий приём заявок.
3. Добавить индексируемость по окружениям, canonical, robots.txt, sitemap.xml; оставить заглушки вне индекса.
4. На публичном адресе проверить HTML, статусы, canonicals и sitemap в Google Search Console и Яндекс Вебмастере.
5. Измерить LCP, INP и CLS на мобильных и desktop с полевыми данными или лабораторными замерами, затем исправлять конкретные проблемы.
