# IndexNow для abbio.ru

В `public/<ключ>.txt` лежит файл подтверждения владения доменом. После деплоя он должен отвечать HTTP 200 по адресу `https://abbio.ru/<ключ>.txt` и содержать тот же ключ. Команда проверяет это сама и не отправляет URL, пока файл не опубликован.

## Автоматическая отправка статей

На production публикация, публикация новой редакции и снятие статьи с публикации создают уведомления для URL статьи и `/articles`. Они сохраняются в `abbio_editorial.indexnow_outbox` в той же транзакции, что изменение публикации. Черновики, неизменённая опубликованная редакция и идемпотентные повторы новых событий не создают.

После COMMIT и ответа API `next/server.after` немедленно запускает отправку. Фоновый обработчик запускается при старте сервера и затем раз в минуту; после ошибки уведомление сохраняется, повтор откладывается от минуты до часа. Перезапуск сервера не теряет очередь. HTTP 200/202 отмечает доставку, записи очищаются через 30 дней. Ошибки IndexNow не отменяют созданную статью и не меняют ответ Make.

Используется существующий публичный ключ домена и официальный `https://api.indexnow.org/indexnow`. Новой переменной для рабочего сайта не требуется. `INDEXNOW_ENABLED=false` отключает отправку; dev и production с loopback-БД автоматически не отправляют тестовые URL. В журналах доступны сообщения `IndexNow accepted` и `notification retained for retry`; токены API не журналируются.

Для остальных страниц и разового обновления SEO после деплоя остаётся ручная команда:

```bash
npm run indexnow -- /services/seo
```

После первого развёртывания IndexNow можно один раз отправить все URL из **боевого** sitemap:

```bash
npm run indexnow -- --all
```

Команда принимает несколько путей или полных URL только домена `https://abbio.ru`. Для удалённой страницы можно передать прежний путь отдельно. Не запускайте `--all` при каждой сборке: IndexNow предназначен для новых, изменённых и удалённых URL после их фактической публикации. HTTP 200/202 подтверждает приём уведомления, а не включение страницы в поиск.

IndexNow используется участвующими поисковиками и не заменяет Google Search Console или `sitemap.xml`. Ключ публичен по требованиям протокола; он не связан с токеном Telegram или иными секретами сайта.

Протокол: https://www.indexnow.org/documentation
