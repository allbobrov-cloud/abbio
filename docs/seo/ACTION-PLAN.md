Связанный аудит: [FULL-AUDIT-REPORT.md](./FULL-AUDIT-REPORT.md).

## 1. До открытия индексации

- [x] Владелец подтвердил основной домен `abbio.ru`.
- [ ] Владелец определяет целевые регионы и приоритетные услуги для карты запросов.
- [x] Владелец подтвердил 29.09.2026 текущие факты сайта, включая имена, роли, портреты команды и показатели кейсов. Устаревшие пометки о демонстрационной команде удалены из интерфейса. Подтверждённые контакты остаются отдельной задачей.
- [ ] Подключить доставку всех форм, проверить успешное и ошибочное отправление, затем привести подписи CTA и сообщения об отправке к реальному поведению.
- [ ] Подготовить необходимые тексты обработки данных для форм на основе данных владельца.
- [x] 29.09.2026 владелец прямо поручил открыть индексацию. Общий `noindex` снят; страница-заглушка `/articles` остаётся закрытой.
- [x] Добавлены `robots.txt` и автогенерируемый `sitemap.xml`: статические страницы находятся при сборке в `src/app`, услуги и кейсы берутся из данных сайта. Карта содержит канонические URL без заглушки `/articles`, ссылка на неё есть в robots.txt.
- [x] Добавлены `metadataBase` и абсолютные self-canonical для 16 существующих страниц. Проверено по статическому HTML production-сборки 29.09.2026; публичный хост и редиректы перепроверить после выкладки.
- [x] В `next.config.ts` настроен именно 301-редирект `www.abbio.ru` → `https://abbio.ru` с сохранением пути и параметров. Локально 29.09.2026 проверены `/` → `https://abbio.ru/` и `/services/seo?utm_source=test` → `https://abbio.ru/services/seo?utm_source=test`.
- [ ] На хостинге добавить `www.abbio.ru` как обслуживаемый HTTPS-хост, выпустить действительный TLS-сертификат и направить запросы к редиректу (на уровне прокси или Next.js). На 29.09.2026 публичный `http://www.abbio.ru` делает 301 на проблемный `https://www.abbio.ru`; HTTPS не проходит проверку сертификата и при диагностическом запросе без проверки отвечает 404. Кодовый редирект не может сработать до корректной маршрутизации запроса хостингом.

- [ ] Добавить внутренние ссылки из смысловых блоков услуг на подходящие кейсы и обратно, не ограничиваясь общей навигацией.

## 3. На опубликованном домене

- [ ] Подтвердить владение в Google Search Console и Яндекс Вебмастере; отправить sitemap и проверить реальные причины исключения страниц.
- [ ] Настроить аналитику и события отправки заявки/клика по контактам; проверить получение событий без тестовых заявок в отчётах.
- [ ] Измерить Core Web Vitals на mobile и desktop: LCP до 2,5 с, INP менее 200 мс, CLS менее 0,1 как ориентиры Google. Оптимизировать только найденные узкие места.
- [ ] Через несколько недель проверить индексируемость, запросы, CTR и посадочные страницы; корректировать контент по фактическим данным, не обещая позиции и сроки.

**Открытые входные данные:** регион продвижения, приоритетные услуги, утверждённые контакты, канал получения заявок, тексты обработки данных. Состав команды и опубликованные факты подтверждены владельцем 29.09.2026. Основной домен: `abbio.ru`.

## Проверка после публикации

После выкладки проверить на `https://abbio.ru` `index, follow`, self-canonical, URL в `/sitemap.xml`, ссылку на sitemap в `/robots.txt` и отдельный `noindex` у `/articles`. Открытие индексации не гарантирует попадание страниц в поиск; ошибки доставки форм и редиректа `www` остаются отдельными задачами.
