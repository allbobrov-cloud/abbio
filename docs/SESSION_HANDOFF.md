- Рабочая ветка: `publish-abbio`, она отслеживает `abbio/main`.
- Целевой remote: `abbio` → `https://github.com/allbobrov-cloud/abbio.git`.
- `origin` и локальная ветка `main` относятся к историческому репозиторию `MarketingAgency`; не переключайтесь на них и не пушьте туда без прямой просьбы владельца.
- Публикация ABB.IO уже была сделана в `abbio/main` коммитом `7b2836b` (`Publish ABB.IO website`). Последующие локальные изменения сами по себе не опубликованы.

Перед Git-операциями обязательно выполните `git status --short`, сохраните чужие изменения и не используйте разрушительные `git reset --hard` или `git checkout --`.

Локальный запуск:

```powershell
cd "C:\AI Work\AI Work\Codex\Маркетинговое агенство\Сайт"
```

Обычно сайт открывается на `http://127.0.0.1:3000`. Если сервер уже запущен, не поднимайте второй экземпляр без необходимости.

## Что уже есть на главной

Порядок в `src/app/page.tsx`: hero → ситуации клиента → услуги → кейсы → демо-отчёт → отраслевой блок → путь клиента → процесс → форматы работы → команда. Контактная форма находится в footer, а общая модальная форма открывается из CTA.

- `src/components/CasesSection.tsx` и `CasesSection.module.css` — кейсы;
- `src/components/AgencyHeader.tsx`, `AgencySections.tsx`, `Agency.module.css` — навигация, процесс, команда, footer;
- `src/components/ContactDialog.tsx`, `FooterContactForm.tsx`, `src/lib/contactForm.ts` — формы и маска телефона;
- `src/lib/content.ts` — редактируемые тексты и данные.

## Неподвижные рамки

- Визуальный язык: тёмный premium B2B/editorial, графитово-синий фон, фиолетовый акцент, строгая сетка, крупная типографика, спокойные интеракции.
- Один блок отвечает на один новый вопрос посетителя. Не возвращайте повторы о «системе», «росте» и «аналитике» под разными заголовками.
- Не придумывайте реальные кейсы, клиентские цифры, гарантии, контакты, состав команды или отзывы. Метрики возможны только с источником и периодом.
- Иллюстрации AI и интерфейсные схемы — декоративные, не доказательства результатов. Демо Google Sheets — пример структуры отчёта, не клиентские показатели.
- У форм сейчас нет backend-доставки: валидная отправка должна честно сообщать, что данные не отправлены и не сохранены, пока владелец не подключит сценарий.
- Не затрагивайте внутренние страницы, Git-историю или внешние сервисы без прямой задачи владельца.

## Текущий уровень и проверка

Последний мобильный quality pass проверял главную на 390×844, 360×800 и 320×700: нет горизонтального overflow и ошибок консоли; меню, направления hero, сценарии и модальная форма работают; touch-цели не меньше 24px; остаётся одно активное изображение hero; snap-ленты имеют доступные подписи. `npm run lint` и production `npm run build` проходили для актуального кандидата.

После правок фронтенда запускайте:

```powershell
npm run lint
npm run build
```

При изменении интерфейса быстро проверьте desktop и mobile, меню, CTA, переключатели, фокус с клавиатуры, отсутствие переполнения и console errors. Не заявляйте, что это полный аудит WCAG, SEO или производительности.
