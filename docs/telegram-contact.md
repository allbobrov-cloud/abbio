# Заявки сайта → Telegram

Формы диалога, футера и страницы задачи используют один маршрут `/api/contact`. Браузер не видит токен бота. До включения интеграции формы продолжают открывать подготовленное письмо на `info@abbio.ru`; при включении они отправляют заявку серверу, а сервер вызывает Telegram Bot API `sendMessage`. Подтверждение «заявка отправлена» появляется только после успешного ответа API.

## Подключение

1. Создать бота через BotFather и добавить его в личный чат или закрытую группу, куда должны приходить заявки. В группе отправить команду, адресованную боту, например `/start@abbioru_bot`.
2. Узнать `chat.id` через `getUpdates` Bot API. У группы ID обычно отрицательный; не путать его с ID самого бота. Бот должен иметь право отправлять сообщения в выбранный чат.
3. Задать на сервере `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Токен не записывать в репозиторий и не передавать в `NEXT_PUBLIC_*`. Локально использовать `.env.local`, пример имён — в `.env.example`.
4. До активации проверить требования к обработке персональных данных, включая возможную трансграничную передачу через Telegram, уведомление Роскомнадзора по статье 12 закона № 152-ФЗ и фактическое место первичного сбора данных. Код и политика описывают поток данных, но не подтверждают выполнение этих организационных действий.
5. После проверки установить `TELEGRAM_CONTACT_ENABLED=true` и перезапустить сайт. `GET /api/contact` должен вернуть `{"mode":"telegram"}`. Отправить тестовую заявку с вымышленными данными и проверить сообщение в целевом чате. Затем проверить текст `/privacy` в активном режиме.

Пока переменные не заданы или флаг не включён, `GET /api/contact` возвращает `{"mode":"email"}`, а `POST` отвечает `503` без отправки. Если Telegram API не подтвердил доставку, форма сообщает об ошибке и не показывает ложный успех. Ограничение частоты и скрытое поле сокращают автоматический спам; при его росте нужен лимит на уровне входного прокси.

Ссылки: [Telegram Bot API — sendMessage](https://core.telegram.org/bots/api#sendmessage), [закон № 152-ФЗ, статьи 12 и 18](https://mintrud.gov.ru/docs/laws/130).
