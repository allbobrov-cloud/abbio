- 22: сохранён редакционный контекст ABBiO, исправлено обращение к ОборонСпецСплаву, HTML заменён на JSON с Markdown H2/H3, добавлены metadata и ограничения API. Заголовок входит в общий результат; отдельный промпт мотошколы/Дзена удалён.

- 16: сохранены модель и существующий доступ OpenRouter; промпт экранируется `escapeJSON`. Используется ответ Images API `data[].b64_json`.
- 24: base64 превращается в бинарные данные; POST `/api/articles/assets`, MIME PNG. Полученный локальный URL используется для `coverImage`.
- 25: Make Create JSON безопасно сериализует строки, переносы, кавычки и массивы. `relatedCases`/`relatedArticles` пустые; связанные услуги только из текущих slug сайта. Автор ABBiO, статус draft. Slug дополнен ID исходной строки для уникальности.
- **19**: HTTP legacy v3, POST `https://abbio.ru/api/articles`, Raw JSON, body `{{25.json}}`, Bearer авторизация сайта, `Idempotency-Key: abbio:{{1.id}}:create:v1`, parse response включён, HTTP-ошибки останавливают выполнение. Старый bogov endpoint, multipart и HASH_KEY удалены.
- 26: POST `/api/articles/{{19.data.id}}/publish` с `expectedRevision`; собственный стабильный Idempotency-Key. 21 пропускается только при `published` и совпадении опубликованной редакции.
- Включены последовательное выполнение и сохранение incomplete executions; исходное `confidential: false` сохранено, поскольку confidential блокирует сохранение данных незавершённых запусков. Для ошибки доставки возобновлять incomplete execution с сохранёнными данными и ключами, а не заново генерировать материал.

## Проверки и запуск

API Make подтвердил сохранённую схему и `isinvalid: false`, `isActive: false`. В интерфейсе проверены настройки модуля 19. Временный отдельный сценарий с синтетическим JSON проверил Parse JSON, Create JSON и HTTP GET: выполнение `2799bd3eb2414abbb3cd808b798cbac1`, статус 1; временный сценарий удалён. Генерация изображений/текста, создание боевой статьи и удаление реальной темы не выполнялись.

Боевой `/api/articles/00000000-0000-4000-8000-000000000000` пока возвращает **404 text/html**. Модуль 23 допускает продолжение только при **404 JSON `article_not_found`**, что означает готовый защищённый API с доступной схемой БД. Обычная 404, 401 или 503 останавливают цепочку до генерации. API токен в Make соответствует локальному `ARTICLES_API_TOKEN`; на сервер нужно поставить тот же токен.

Полный production-проход ещё не проверен: сначала отдельно разрешённый deploy сайта, серверные переменные, `npm run articles:migrate` из сети хостинга, затем одна контролируемая публикация и проверка удаления её темы. Модель, размер реального изображения и фактический ответ поставщика проверяются при этом проходе.
