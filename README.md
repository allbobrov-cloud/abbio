# ABB.IO

Сайт агентства ABB.IO: дизайн, сайты и маркетинг для бизнеса.

## Локальный запуск

Установите зависимости:

```bash
npm install
```

Запустите development-сервер:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверка production-сборки

```bash
npm run lint
npm run build
npm run start
```
